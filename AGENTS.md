# Contexto del proyecto

Antes de modificar este proyecto, lee `PROJECT_MEMORY.md`. Contiene las decisiones de la propietaria, el estado del inventario, las funcionalidades terminadas y las comprobaciones realizadas.

Actualiza esa memoria cuando cambien decisiones, datos confirmados o funcionalidades importantes. Verifica la base de datos antes de modificar inventario: los valores documentados son una referencia de la última sesión, no sustituyen los datos actuales.

Trabaja únicamente en este proyecto. No modifiques los proyectos vecinos. Conserva los cambios existentes y las copias privadas de `.local/`. No registres contraseñas ni tokens en la documentación.
