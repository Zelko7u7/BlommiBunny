**Instrucciones para Codex:** Este documento es la fuente de verdad de las descripciones proporcionadas por la propietaria. Relaciona cada entrada con el registro real del catálogo mediante nombre normalizado/ID existente, sin crear duplicados. Respeta tildes y puntuación. Los nombres de archivos listados abajo son **patrones identificativos**, no rutas verificadas del repositorio. Inspecciona el ZIP `Productos.zip` y la carpeta `Bloomiimages` antes de asignar rutas. Los números 1, 2, 3 indican fotos de una misma referencia salvo cuando el nombre contiene una variante (#2, #3, #4, #6). Conserva la imagen principal existente, usando el ZIP para galería secundaria; solo usa una imagen del ZIP como portada cuando el producto carezca de portada.
